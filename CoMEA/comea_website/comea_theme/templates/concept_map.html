Conheça mais sobre Mapas Conceituais no Mapear

A proposta desse site é reunir materiais, conceitos e ferramentas que auxiliem professores no uso de mapas conceituais em diferentes contextos educacionais. O projeto foi pensado especialmente para apoiar práticas pedagógicas inclusivas, considerando salas de aula compostas por estudantes neurotípicos e neurodivergentes, incluindo alunos com dislexia, público central da pesquisa. O site e os materiais disponibilizados buscaram seguir recomendações de acessibilidade voltadas a pessoas com dislexia, inspiradas em orientações da British Dyslexia Association.

{% trans "Topological Taxonomy" %}

{% trans "What is it?" %}

{% trans "The Topological Taxonomy is a classification tool developed by the Conéctate al Conocimiento Project in Panama to assess the structural complexity of concept maps. It consists of 7 levels (0 to 6) that analyze the external structure of the map, not its semantic content. It is inspired by Bloom's Taxonomy and aims to provide a 'common language' to describe the evolution of students' concept maps." %}

{% trans "How is it measured?" %}

{% trans "The taxonomy evaluates 5 structural criteria:" %}

{% trans "Example" %} {% trans "Criterion" %} {% trans "Description" %}
{% trans "Concept vs. Long Texts" %} {% trans "Checks whether nodes contain short concepts or long explanations." %}
{% trans "Linking words" %} {% trans "Checks whether words connecting concepts are present." %}
{% trans "Branching" %} {% trans "Counts the number of nodes from which two or more connections emerge." %}
{% trans "Hierarchical Depth" %} {% trans "Measures the number of levels between the root concept and the furthest concept." %}
{% trans "Cross-links" %} {% trans "Identifies connections between different branches of the map." %}

{% trans "Classification rules:" %}

  • {% trans "To be classified at a given level, the map must meet all the criteria for that level." %}
  • {% trans "If a criterion is missing, the map is classified at the previous level." %}

{% trans "Proposition Evaluation" %}

{% trans "What are propositions?" %}

{% trans "Propositions are the fundamental units used to represent a concept map in a textual format that can be processed computationally. Each proposition is derived from a relationship in the concept map and is structured as a triplet:" %}

{% trans "Proposition = (Head Concept, Relationship, Target Concept)" %}

{% trans "For example, in a concept map about 'Molecules', a proposition might be: 'molecules can be water' (Head Concept: molecules, Relationship: can be, Target Concept: water). Each proposition is then converted into a sentence and transformed into a numerical vector called an embedding using deep learning models. This allows the computer to understand and compare the meaning of propositions mathematically." %}

{% trans "How are propositions evaluated?" %}

{% trans "The evaluation of propositions occurs through the following steps:" %}

1

{% trans "Extraction" %}

{% trans "All propositions (triplets) are extracted from each student's concept map." %}

2

{% trans "Comparison" %}

{% trans "The system will compare each proposition extracted from the student's map with the essential concepts extracted from a reference document, looking for concepts present or absent in the concept map." %}

3

{% trans "Classification" %}

{% trans "Based on the reference document, each proposition extracted from the student's concept map will be classified as 'Correct,' 'Partially correct,' or 'Incorrect' by a Generative Artificial Intelligence model." %}

{% trans "This approach allows for a semantic comparison of concept maps, going beyond simple word matching to understand the meaning and relationships expressed by the students." %}

{% trans "Structure Classification" %}

{% trans "Based on the research by Hay and Kinchin, concept maps can reveal three distinct types of cognitive structures, or 'typologies of thought.' These structures — Spoke, Chain, and Network — represent different ways knowledge is organized in a student's mind. Identifying them helps educators understand the depth and quality of a student's understanding." %}

{% trans "Spoke Structure" %} {% trans "Chain Structure" %} {% trans "Network Structure" %}

{% trans "This is the simplest structure. It resembles a wheel, where a single central concept is connected to several related ideas, but those peripheral ideas are not connected to each other." %}

{% trans "This structure is a linear sequence of concepts linked in a single line. It represents a procedural or sequential understanding, often focused on cause and effect or chronological order (e.g., a step-by-step process)." %}

{% trans "This is the most complex and sophisticated structure. It features multiple concepts connected by numerous, meaningful links in a web-like fashion, showing a rich hierarchy and many cross-connections." %}

{% trans "Indicates a naive or superficial understanding. The student knows that certain concepts are related to the main topic but cannot explain the relationships between the secondary concepts. It is often a sign of a beginner's knowledge." %}

{% trans "Indicates a goal-oriented, but rigid, understanding. This type of thinking is good for following procedures and achieving specific goals. However, it is fragile. It can reflect 'surface learning' where the sequence is memorized but the broader connections are not understood." %}

{% trans "Indicates expertise and deep, meaningful learning. They show that a student can integrate new knowledge with existing knowledge, see complex relationships, and understand a topic from multiple perspectives." %}

  • {% trans "Addition of new knowledge:" %} {% trans "Additions to central concept do not interfere with associated concepts." %}
  • {% trans "Deletions of concepts (corrections of misunderstanding):" %} {% trans "Have no effect on overall structure, except if misunderstanding involves the central concept." %}
  • {% trans "Addition of new knowledge:" %} {% trans "Cannot cope with additions near the beginning of the sequence, as they can disrupt the train of thought. If a new concept is introduced in the middle of the chain, the entire structure can collapse because the logic is linear and interdependent." %}
  • {% trans "Deletions of concepts (corrections of misunderstanding):" %} {% trans "Disrupt the sequence below the deletion." %}

{% trans "Additions/deletions may have varying influence as 'other routes' are often available through the map. This structure is robust and adaptable, allowing for the easy addition or deletions of concepts without collapsing." %}

{% trans "In summary, as a learner progresses, their cognitive structure ideally evolves from simple spokes (superficial knowledge) into linear chains (procedural knowledge), and finally into complex networks (integrated expertise), though learning can happen within each structure without changing its fundamental shape." %}
